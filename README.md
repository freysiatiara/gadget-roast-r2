Entry for the make.fun bounty [One-Line Roast: The Gadget You Use Every Day](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

The entry is a single line, roasting a gadget I use every day:

**My printer works fine until the document matters — then it jams, blinks, and looks at me like I loaded the paper wrong.**

`main.py` (stdlib only) copies `entry.txt` verbatim to the output path
(`/output/entry.txt` by default; `ENTRY_OUTPUT` / `OUTPUT_DIR` /
`MAKEFUN_OUTPUT_DIR` override it), resolving every path from its own
location, never from the working directory.
