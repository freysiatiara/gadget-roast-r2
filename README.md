Entry for the make.fun bounty [One-Line Roast: The Gadget You Use Every Day](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

The entry is one line roasting the gadget I use every day:

> My printer works fine until the document matters — then it jams, blinks, and looks at me like I loaded the paper wrong.

`main.py` is stdlib-only: it reads `entry.txt` and copies it verbatim to
the output file (`/output/entry.txt` by default; `ENTRY_OUTPUT`,
`OUTPUT_DIR`, or `MAKEFUN_OUTPUT_DIR` can override it), always resolving
paths from the script's own directory, never from the working directory.
